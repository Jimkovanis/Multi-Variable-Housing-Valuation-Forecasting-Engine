# Multi-Variable Housing Valuation & Forecasting Engine

A regression pipeline that predicts residential sale prices from the [Ames Housing
dataset](https://www.kaggle.com/datasets/prevek18/ames-housing-dataset) (2,930 homes,
82 raw features), and a reusable "forecasting engine" that predicts a price for any
new house given a partial set of features.

## Problem

Given structural, quality, and location attributes of a house, predict its sale price.
This is a classic multi-variable regression problem: no single feature explains price
well on its own, but a combination of size, quality, age, and location does.

## Approach

1. **EDA** — `SalePrice` is right-skewed (a few luxury homes pull the distribution's
   tail out), so the model is trained on `log1p(SalePrice)` and predictions are
   converted back with `expm1()`. `Overall Qual` (r=0.80) and `Gr Liv Area` (r=0.71)
   are the strongest single predictors.

2. **Cleaning** — most "missing" values in this dataset aren't actually missing data;
   `NaN` in a column like `Pool QC` means the house has no pool. These are filled with
   a sentinel value rather than dropped, which preserves the full dataset. Genuinely
   missing values (e.g. `Lot Frontage`) are imputed from training-set statistics.

3. **Feature engineering** — derived features include `House Age`, `Total SF`
   (combining basement + 1st + 2nd floor area), `Total Bath`, and binary amenity flags.
   Quality/condition columns (Ex/Gd/TA/Fa/Po) are ordinal-encoded to preserve their
   natural ranking; unordered categoricals (Neighborhood, Zoning, etc.) are one-hot
   encoded. Final feature set: 246 columns.

4. **Modeling** — Linear Regression, Ridge, and Lasso are trained and compared.
   With 246 features on ~2,300 training rows, plain linear regression overfits
   (large train/test performance gap); Ridge and Lasso close that gap via
   regularization, and Ridge is selected as the final model.

## Results

| Model | Train R² | Test R² | Test MAE |
|---|---|---|---|
| Linear Regression | 0.937 | 0.880 | $14,762 |
| **Ridge (selected)** | 0.917 | **0.917** | $15,822 |
| Lasso | 0.912 | 0.916 | $15,879 |

Ridge generalizes best to unseen houses (test R² actually exceeds plain linear
regression's, despite a lower training score) — evidence that regularization
successfully controls overfitting on this feature-rich, moderately-sized dataset.
Lasso additionally zeroes out 152 of 246 features, offering a useful, more
interpretable subset of what actually drives price.

## Usage

```bash
pip install -r requirements.txt

# Train (reads data/AmesHousing.csv, writes model artifacts to models/)
python src/train.py

# Predict on a new house
python src/predict.py
```

Or use the engine directly in Python:

```python
from src.predict import HousingValuationEngine

engine = HousingValuationEngine()
price = engine.predict({
    "Gr Liv Area": 1800,
    "Overall Qual": 7,
    "Neighborhood": "NAmes",
    "Year Built": 2005,
    # ...any subset of raw Ames Housing columns; missing fields are imputed
})
print(f"${price:,.0f}")
```

## Known limitations

- Predictions on partially-specified houses fall back to training-set medians/modes
  for any unsupplied fields, so accuracy improves with more complete input.
- Trained on Ames, Iowa data (2006–2010 sales) — not calibrated for other markets
  or time periods without retraining.
- Linear models capture linear and one-hot-encoded relationships only; a tree-based
  model (Random Forest / XGBoost) could likely improve accuracy further at the cost
  of interpretability.
